# Plan to Fix useSeo.js Meta Tag Error

## Problem
The error `meta.setProperty is not a function` occurs in `useSeo.js` at line 102 in the `updateMetaTag` function. This happens because `HTMLMetaElement` does not have a `setProperty` method - it only has `setAttribute` for setting HTML attributes.

## Root Cause
The code incorrectly uses `meta.setProperty(attribute, content)` when trying to set the 'property' attribute on meta tags for Open Graph tags. The correct method is `meta.setAttribute('property', attribute)`.

## Solution Steps

1. **Edit updateMetaTag function**: Replace the incorrect `setProperty` calls with `setAttribute`.

   - For creating new meta tags: Change the conditional logic to use `setAttribute(nameOrProperty, attribute)` for both 'name' and 'property' cases.
   
   - For updating existing meta tags: Remove the redundant `setProperty` call since the 'property' or 'name' attribute is already set.

2. **Verify the fix**: Run the application and navigate to a page that triggers SEO updates to ensure the error is resolved and meta tags are properly set.

## Files to Modify
- `resources/js/composables/useSeo.js`: Lines 92-93, 101-103
