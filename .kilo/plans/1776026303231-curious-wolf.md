# CRM Enhancement Plan for LegalLaravel

## Overview
This plan outlines steps to enhance existing CRM features in the Laravel-based Indian Legal Firm Management System, based on the requirements in `crm-todo.md`. The system already has robust CRM foundations including client profiles, case management, document handling, billing, tasks, and calendar integration. The focus will be on completing gaps, adding advanced features, ensuring compliance, and improving UX.

## 1. Core CRM Features Enhancement
### A. Client Profiles & Management
**Current State:** Client model exists with basic fields and relationships to cases, documents, invoices. KYC status and consent tracking are present.

**Enhancements Needed:**
- Add Indian-specific fields: Aadhaar, PAN, GSTIN to clients table.
- Enhance segmentation with case type and revenue categorization.
- Implement client lifetime value (LTV) calculation.

**Steps:**
1. Update `create_clients_table` migration to add Aadhaar, PAN, GSTIN fields (varchar, nullable).
2. Update Client model to include new fields and validation rules.
3. Add LTV method to Client model calculating total revenue from invoices.
4. Update client profile views to display and edit new fields.

### B. Communication Tracking
**Current State:** InteractionLog and FollowUp models exist. CrmController handles interactions.

**Enhancements Needed:**
- Integrate email/SMS logging via Laravel Mail and APIs (e.g., Msg91 for SMS).
- Automate follow-ups with scheduled jobs.

**Steps:**
1. Add email and SMS logging in CrmController when sending communications.
2. Configure SMS API (Msg91) in services and log sent SMS.
3. Create scheduled job for automated follow-ups using Laravel's task scheduler.
4. Update client profile to show communication history timeline.

### C. Case & Matter Linking
**Current State:** Cases link to clients via pivot and participants. Timeline events exist.

**Enhancements Needed:**
- Add conflict of interest checks before new case creation.
- Ensure 360° client view from profile.

**Steps:**
1. Add conflict check method in CaseController: query existing cases for shared clients/opposing parties.
2. Update client profile view to include linked cases, documents, invoices, tasks in a unified dashboard.
3. Enhance case timeline to include client-specific events.
