# Legal Management System - UI Completion Plan

## Overview
Focus on completing 6 key UI features that have frontend components but lack proper backend API integration. Each feature needs working APIs, data persistence, and real-time synchronization.

## Target Features (UI Exists, Backend/APIs Missing)
1. **Legal Chatbot** - UI + mock store, no real API
2. **Reports Page** - UI complete but data incomplete
3. **Calendar** - No dedicated event APIs
4. **Notifications** - No CRUD API
5. **Client Portal** - No dedicated APIs
6. **Admin Dashboard** - No admin stats APIs

## Current State Analysis
- **Backend**: Laravel 13 with comprehensive models but missing specific APIs for the 6 target features
- **Frontend**: Vue 3 + Pinia with UI components for all 6 features, using mock data/stores
- **Database**: Multi-tenant with legal references and comprehensive schema
- **Authentication**: Sanctum with roles (admin, attorney, paralegal, client)
