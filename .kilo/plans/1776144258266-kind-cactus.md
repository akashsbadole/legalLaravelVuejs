# Fix CSP Violations for IPv6 Localhost in Laravel Vite Development

## Problem
Vite development server is running on IPv6 localhost `[::1]:5173`, but the Content Security Policy (CSP) in `SecurityHeadersMiddleware.php` only allows IPv4 localhost (`localhost` and `127.0.0.1`). This causes CSP violations blocking Vite client scripts, CSS, and JS files.

## Root Cause
- Vite binds to `[::1]:5173` (IPv6 loopback)
- CSP script-src, style-src-elem, and connect-src directives don't include IPv6 equivalents
- Blocked URLs: `http://[::1]:5173/@vite/client`, `http://[::1]:5173/resources/css/app.css`, `http://[::1]:5173/resources/js/app.js`

## Solution
Update the CSP in `app/Http/Middleware/SecurityHeadersMiddleware.php` to include IPv6 localhost addresses with specific port 5173 (Vite dev server port):
- Add `http://[::1]:5173` and `ws://[::1]:5173` to script-src
- Add `http://[::1]:5173` to style-src-elem
- Add `http://[::1]:5173` and `ws://[::1]:5173` to connect-src

1. Edit `SecurityHeadersMiddleware.php`
2. Update CSP string on lines 30, 32, and 35
3. Test that Vite dev server loads without CSP errors
4. Ensure production CSP still works (IPv6 localhost should only be needed in dev)
